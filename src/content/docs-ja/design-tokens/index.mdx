トークンシステムは、一度だけ下せばよい決定の集合です — ただし、コードベースが育っても名前が破綻しないことが前提です。Tailwind CSS v4 のプロジェクトを対象に、トークンセットを意図的に小さく保つ方法、2 層のサイズ設計、複数名前空間の命名、アプリケーションのスペーシングアーキテクチャ、`z-index` スケール、ディスプレイスケール、トークンの Lint を扱います。
