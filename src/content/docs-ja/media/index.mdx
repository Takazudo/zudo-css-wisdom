メディアは、CSS が画像・動画・埋め込みコンテンツのサイズとフィットをどう決めるかを扱うカテゴリです。`aspect-ratio`、`object-fit` / `object-position`、レスポンシブ画像、レターボックス固定比率ステージを扱います。
