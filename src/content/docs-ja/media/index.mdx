Media は CSS が画像・動画・埋め込みコンテンツのサイズとフィットをどう扱うかを扱うカテゴリです。ここでは `aspect-ratio`、`object-fit` / `object-position`、レスポンシブ画像、レターボックス固定比率ステージを扱います。
